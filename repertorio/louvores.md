# Biblioteca de Louvores

Repertório configurável pelo líder do ministério de louvor, usado para facilitar a montagem do cronograma. Tudo aqui, músicas, campos e categorias, é definido e mantido pelo próprio líder, sem valores fixos pré-definidos pelo sistema.

## Como usar

1. O líder cadastra as músicas do próprio repertório nessa lista, do jeito que fizer sentido para o ministério.
2. Ao montar a escala em `escalas/escalas.md`, o líder escolhe as músicas direto dessa lista.
3. O líder pode adicionar, editar, reordenar ou remover colunas e categorias conforme a necessidade (a tabela abaixo é só um ponto de partida).

## Categorias

O líder define as categorias que fizerem sentido para o ministério. Sugestão de ponto de partida (pode ser totalmente alterada):

- Abertura
- Adoração
- Celebração
- Ceia/Comunhão
- Ministração/Altar
- Encerramento

## Observações

- Este arquivo é de propriedade do líder do ministério de louvor. Ele decide o que entra, sai ou muda no repertório.
- Se uma música sair de uso, mova para uma seção de "Repertório antigo" em vez de apagar, para manter o histórico.
