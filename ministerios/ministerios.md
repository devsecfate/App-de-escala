# Ministérios

Cadastro dos ministérios da igreja. A lista abaixo é configurável, cada igreja pode renomear, adicionar, remover ou dividir ministérios do jeito que fizer sentido para ela.

| Ministério | Líder | Funções (sugestão inicial) | Observações |
|---|---|---|---|
| Tecnologia (projeção e luz) | | Projeção, Som, Luz | |
| Mídias | | Fotografia, Redes sociais, Transmissão | |
| Louvor | | Vocal, Violão, Teclado, Bateria, Baixo | Usa `repertorio/louvores.md` para o cronograma |
| Acolhimento | | | |
| Evangelismo | | | |
| Social | | | |
| Espiritualidade | | | |

> Lista configurável: esta é a estrutura desta igreja. Outras igrejas usando o app podem editar esta tabela livremente, renomeando ministérios, juntando ou separando áreas (ex: separar "Tecnologia" em "Projeção" e "Luz"), ou criando novos conforme sua realidade. As funções também são sugestão inicial: cada líder cadastra as funções do próprio ministério pelo app.
